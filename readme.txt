1. Подсчет файлов и вывод по убыванию длины
nano 1_1.sh
ctr o ctr x
chmod +x 1_1.sh
./1_1.sh /path/to/directory
например /home/user/documents


2. Удаление временных файлов с логом
nano 1_2.sh
ctr o ctr x
chmod +x 1_2.sh
./1_2.sh /tmp .tmp 60
